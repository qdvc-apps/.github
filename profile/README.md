## qdvc-apps

Quick and dirty, vibe-coded (QDVC) applications. A project of [@blairwang-online](https://github.com/blairwang-online/) - but keen for collaborators!

Most repos keep an `ai-assistance-logs/` or `vibe-coding/` folder recording the conversational build, so you can see how each app came to be.

### Command-line Python programs

- 📬 [qdvc-gtd-eml](https://github.com/qdvc-apps/qdvc-gtd-eml) - implementation of GTD workflow on a collection of EML email messages
- ❤️ [qdvc-health-dashboard](https://github.com/qdvc-apps/qdvc-health-dashboard) - generates single-page analytics dashboard for personal health stats
- 🖥️ [qdvc-super-switcher](https://github.com/qdvc-apps/qdvc-super-switcher) - switch between open windows using Super (Win) key on MATE and maybe XFCE
- 📑 [qdvc-apa-citations-check](https://github.com/qdvc-apps/qdvc-apa-citations-check) - citations check for APA referencing
- 🔎 [qdvc-quickprisma](https://github.com/qdvc-apps/qdvc-quickprisma) - turn a pile of `.bib` exports into a PRISMA 2020 flow diagram, via offline browser-based screening pages
- 🌳 [qdvc-gioia-diagram](https://github.com/qdvc-apps/qdvc-gioia-diagram) - generate a Gioia-style data structure diagram from a three-column CSV
- 🎙️ [qdvc-podcaster](https://github.com/qdvc-apps/qdvc-podcaster) - static site generator for a podcast: Markdown in, homepage + episode pages + RSS/iTunes feed out
- 📚 [qdvc-markdownpedia](https://github.com/qdvc-apps/qdvc-markdownpedia) - Markdown-based wiki tool (`mdwiki.py`)
- 📌 [qdvc-family-noticeboard](https://github.com/qdvc-apps/qdvc-family-noticeboard) - family noticeboard (`noticeboard.py`)

### Python desktop applications for Linux (GTK3/GTK4)

Common spec: [qdvc-python-gtk-app-specification](https://github.com/qdvc-apps/qdvc-python-gtk-app-specification)

- 📖 [qdvc-bibliotheca](https://github.com/qdvc-apps/qdvc-bibliotheca) - simple native GTK3 bibtex and PDFs manager, similar to EndNote, JabRef, Zotero
- 🕒 [qdvc-countdowns](https://github.com/qdvc-apps/qdvc-countdowns) - simple native GTK3 countdown list, similar to Bears Countdown
- 🖥️ [qdvc-display-toggle](https://github.com/qdvc-apps/qdvc-display-toggle) - quickly change multi-monitor arrangement using Super+P (Win+P) on MATE and maybe XFCE
- 🧰 [qdvc-equip](https://github.com/qdvc-apps/qdvc-equip) - native GTK3/GTK4 asset management (tools, equipment, materials)
- 📒 [qdvc-markdown-notebook](https://github.com/qdvc-apps/qdvc-markdown-notebook) - simple native GTK3 Markdown editor, similar to Obsidian, FSNotes, Markor
- 😀 [qdvc-nice-mail](https://github.com/qdvc-apps/qdvc-nice-mail) - emoji picker, reusable phrases, plaintext mail signatures and note-to-self `.eml` writer
- 🖼️ [qdvc-tadaima](https://github.com/qdvc-apps/qdvc-tadaima) - read-only GTK4/libadwaita photo browser for folders you choose; never touches your files
- 🌐 [hernantz-timezones](https://github.com/qdvc-apps/hernantz-timezones) - fork of [hernantz/timezones](https://github.com/hernantz/timezones), a timezone clocks app with a native GTK4/libadwaita UI

### Native macOS applications (Swift)

- 📖 [qdvc-bibliotheca-mac](https://github.com/qdvc-apps/qdvc-bibliotheca-mac) - macOS edition of qdvc-bibliotheca
- 📬 [qdvc-gtd-eml-mac](https://github.com/qdvc-apps/qdvc-gtd-eml-mac) - macOS edition of qdvc-gtd-eml
- 😀 [qdvc-nice-mail-mac](https://github.com/qdvc-apps/qdvc-nice-mail-mac) - SwiftUI edition of QDVC Nice Mail; shares its workspace format with the Linux edition
- 📅 [qdvc-meetings-mac](https://github.com/qdvc-apps/qdvc-meetings-mac) - keep a record of meetings, attendees, notes, decisions and action items as plain YAML files
- 🔬 [qdvc-autolitreview-tester](https://github.com/qdvc-apps/qdvc-autolitreview-tester) - checks and organises test-run artifacts for an automated literature review tool, with CSV/HTML/Markdown export

### Windows applications (C#)

- 😀 [qdvc-nice-mail-windows](https://github.com/qdvc-apps/qdvc-nice-mail-windows) - Windows edition of QDVC Nice Mail

### Android applications (Kotlin)

Common spec: [qdvc-android-app-specification](https://github.com/qdvc-apps/qdvc-android-app-specification)

- ☑️ [qdvc-checklists-android](https://github.com/qdvc-apps/qdvc-checklists-android) - open a Checklist Studio workspace, tick items off, and keep a CSV audit trail
- 🗒️ [qdvc-nts-android](https://github.com/qdvc-apps/qdvc-nts-android) - Note to Self: notes and self-chats stored as folders of Markdown plus image payloads
- 🐱 [qdvc-cat-android](https://github.com/qdvc-apps/qdvc-cat-android) - fast plaintext viewer with syntax highlighting, available from "Open with"
- 📊 [qdvc-csv-android](https://github.com/qdvc-apps/qdvc-csv-android) - CSV viewer with a sticky header row, available from "Open with"
- 🕒 [qdvc-countdowns-android](https://github.com/qdvc-apps/qdvc-countdowns-android) - Android edition of qdvc-countdowns
- 📒 [qdvc-markdown-notebook-android](https://github.com/qdvc-apps/qdvc-markdown-notebook-android) - Android edition of qdvc-markdown-notebook

### Multi-part suites

- 📰 [qdvc-paperpod-suite](https://github.com/qdvc-apps/qdvc-paperpod-suite) - reading and organisation app for a 7" Kaleido 3 e-paper Android tablet, plus a GTK4 desktop companion that pre-bakes everything it displays

### Single-page web apps (run entirely in the browser)

- 📝 [qdvc-html-to-markdown-SPA](https://github.com/qdvc-apps/qdvc-html-to-markdown-SPA) - paste HTML, get clean, human-readable Markdown
- 🗒️ [stickies](https://github.com/qdvc-apps/stickies) - a mat for sticky notes with Now and Later panels; JSON import/export
- ⏰ [clock](https://github.com/qdvc-apps/clock) - clock SPA ([live](https://qdvc-apps.github.io/clock/))
- 🧪 [test-management](https://github.com/qdvc-apps/test-management) - author test suites and cases, execute runs, record verdicts; exports to Markdown + CSV; built for teaching
- 📈 [qdvc-research-pipeline](https://github.com/qdvc-apps/qdvc-research-pipeline) - track research papers from idea to publication with table, kanban and timeline views
